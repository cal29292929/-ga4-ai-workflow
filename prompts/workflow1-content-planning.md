# ワークフロー1: ランディングページ分析 → AIコンテンツ企画

## 概要

GA4のランディングページ分析で発見した「訪問者の関心領域」を基に、生成AIを活用してリード獲得コンテンツ（ホワイトペーパー、eBook等）を企画します。

---

## 🎯 このワークフローで達成できること

- ✅ データに基づいたコンテンツテーマの選定
- ✅ ターゲットオーディエンスの関心を捉えたタイトル案
- ✅ 実践的な目次構成の自動生成
- ✅ リード獲得フォーム設計のヒント

---

## 📊 前提：GA4で確認すべきデータ

### GA4操作手順

1. GA4管理画面 > **レポート** > **ライフサイクル** > **エンゲージメント**
2. **ランディングページ** レポートを開く
3. 以下の指標を確認：
   - セッション数
   - 表示回数
   - エンゲージメント率
   - 直帰率
   - コンバージョン率

### 分析のポイント

| 指標 | 確認内容 |
|-----|---------|
| **セッション数TOP5** | 最も多く訪問されているページ |
| **前期比成長率** | 急成長しているページ（関心の高まり） |
| **エンゲージメント率** | 訪問者が深く読み込んでいるページ |
| **CVRが高いページ** | 購買意欲の高いユーザーが集まるページ |

## 🤖 AIプロンプト（基本版）

### プロンプトテンプレート

```markdown
# 役割
あなたは、BtoBリード獲得に強いコンテンツマーケターです。

# 状況（事実）
GA4のランディングページ分析によると、訪問者の多くが「[カテゴリ名]」のページから流入しています。
これは、訪問者が「[関連するトピック]」に強い関心を持っているという仮説が立てられます。

具体的なデータ:
- [カテゴリ名]ページ: [セッション数]セッション（前期比 [±X%]）
- エンゲージメント率: [X%]
- 推定CVR: [X%]

# 依頼
この「[カテゴリ名]に関心がある層」からリード（メールアドレス）を獲得するための
お役立ち資料（ホワイトペーパー）のタイトル案を5つ、
最も効果的だと思うタイトルの目次案（3〜5章立て）を1つ作成してください。

# 制約条件
- タイトルは40文字以内
- 具体的な数字・期限を含めること（例：「3ヶ月で」「7つの」）
- ベネフィット（得られる成果）を明確にすること
- 目次は各章5分以内で読める分量を想定
```

## 📝 実例：Google Merchandise Store（アパレルカテゴリ）

### 入力するデータ

```markdown
# 役割
あなたは、BtoBリード獲得に強いコンテンツマーケターです。

# 状況（事実）
GA4のランディングページ分析によると、訪問者の多くが以下のページから流入しています:

1. **「New（新商品）」ページ**: 4,348セッション（前期比 +25.7%）
   - 最新トレンド・限定商品への強い関心
   
2. **「Bags」カテゴリ**: 2,498セッション（前期比 +32.1%）
   - 実用性が高く、ギフト需要もある
   
3. **「Apparel」関連**: 合計5,528セッション
   - ファッション・ライフスタイル層がコア

これは、訪問者が「アパレル・ライフスタイルEC業界の最新トレンドと販売戦略」に
強い関心を持っているという仮説が立てられます。

# 依頼
この「アパレル・ライフスタイルEC業界に関心がある層」からリード（メールアドレス）を獲得するための
お役立ち資料（ホワイトペーパー）のタイトル案を5つ、
最も効果的だと思うタイトルの目次案（5章立て）を1つ作成してください。

# 制約条件
- タイトルは40文字以内
- 具体的な数字・期限を含めること（例：「3ヶ月で」「7つの」）
- ベネフィット（得られる成果）を明確にすること
- 目次は各章10分以内で読める分量を想定（全体40ページ程度）
- GA4データ分析の要素を含めること
```

### 期待されるAI回答例

#### タイトル案（5つ）

1. **『2025年版 ECで売れる！アパレル&ライフスタイル商品の新常識｜Google公式データで見る購買トレンド白書』**
   - フック: Google公式データという権威性

2. **『月間売上1.5倍達成！Google Merch Shopに学ぶ"売れるECサイト"の作り方｜実践的UX改善ガイド』**
   - フック: 具体的な数字 + 実践的

3. **『なぜ今「バッグ」カテゴリが売れるのか？｜データで読み解くライフスタイル商品の購買心理と販売戦略』**
   - フック: 疑問形 + 急成長カテゴリ

4. **『「新商品」×「セール」で最大化する購買率｜CVRが2倍になるタイミング別マーケティング戦略』**
   - フック: CVR 2倍という具体的ベネフィット

5. **『【完全ガイド】アパレル・ライフスタイルECの売上を3ヶ月で伸ばす7つの戦略｜GA4データ分析から施策実行まで』** ⭐推奨
   - フック: 完全ガイド + 3ヶ月という期限 + 7つの戦略

#### 最推奨タイトルの目次案

**『【完全ガイド】アパレル・ライフスタイルECの売上を3ヶ月で伸ばす7つの戦略｜GA4データ分析から施策実行まで』**

**第1章: データで見る2025年の購買トレンド（8ページ）**
- GA4分析で判明した「売れるカテゴリ」TOP3
- 新商品への関心急増（+25.7%）の背景
- バッグカテゴリの爆発的成長（+32.1%）の理由
- 流入経路別の購買傾向分析

**第2章: 7つの戦略で購買率を最大化する（18ページ）**
- 戦略1: 新商品の「初動集客」を制する
- 戦略2: バッグカテゴリに学ぶ「用途訴求」の威力
- 戦略3: セール施策の「戦略的タイミング」
- 戦略4: ランディングページ最適化の「黄金法則」
- 戦略5: カート放棄率91.5%を半減させるチェックアウト改善
- 戦略6: モバイルファーストで「スマホCVR」を2倍にする
- 戦略7: リピーター育成で「LTV」を3倍にする

**第3章: GA4で成果を測定・改善する（8ページ）**
- 必ず設定すべきGA4カスタムレポート3選
- 週次チェックすべき5つのKPI
- データから次の打ち手を見つける「PDCA思考法」

**第4章: 3ヶ月実行ロードマップ（4ページ）**
- Month 1: クイックウィン（即効性の高い施策）
- Month 2: 構造改善（中期的な土台作り）
- Month 3: 成長加速（リピーター育成）

**第5章: 実践ツール&テンプレート集（2ページ + ダウンロード特典）**
- GA4カスタムレポートテンプレート
- 商品説明文テンプレート集（50パターン）
- KPIダッシュボード（Googleスプレッドシート）

## 🔧 プロンプトのカスタマイズ方法

### 業界別のカスタマイズ例

#### BtoB SaaS の場合

```markdown
# 状況（事実）
GA4のランディングページ分析によると、訪問者の多くが「料金プラン」「導入事例」「機能比較」ページから流入しています。
これは、訪問者が「[あなたのSaaS製品カテゴリ]の選び方と導入効果」に強い関心を持っているという仮説が立てられます。

# 依頼
この層から「無料トライアル申込」または「資料請求」を獲得するためのホワイトペーパーのタイトル案を5つ、
最も効果的だと思うタイトルの目次案（3章立て）を1つ作成してください。
```

#### メディアサイト（広告収益）の場合

```markdown
# 状況（事実）
GA4のランディングページ分析によると、訪問者の多くが「[特定のトピック]」関連の記事から流入しています。
滞在時間が長く、ページ/セッションも3.5と高いため、深い関心があると推測されます。

# 依頼
この層の関心を維持し、メールマガジン登録を促進するための「完全ガイド」または「チェックリスト」のタイトル案を5つ、
最も効果的だと思うタイトルの目次案（5章立て）を1つ作成してください。
```

## 💡 プロンプト改善のヒント

### より良い回答を得るためのコツ

1. **具体的なデータを含める**
   - ❌ 「訪問者が多い」
   - ✅ 「4,348セッション（前期比 +25.7%）」

2. **ペルソナ情報を追加**
   ```markdown
   # 追加情報
   主要な訪問者層:
   - 職種: ECサイト運営者、マーケティング担当者
   - 企業規模: 中小企業（従業員10-100名）
   - 課題: 広告費をかけずに売上を伸ばしたい
   ```

3. **競合情報を含める**
   ```markdown
   # 競合分析
   競合他社は「[タイトル例]」というコンテンツを提供していますが、
   GA4データ分析という独自の切り口で差別化したいです。
   ```

4. **トーン&マナーを指定**
   ```markdown
   # 制約条件
   - トーン: 専門的だが親しみやすい
   - 対象読者: マーケティング初心者でも理解できる内容
   - 避けるべき表現: 過度な煽り、誇大広告
   ```
