## ワークフロー1: ランディングページ分析とコンテンツ企画

### 📍 目的
訪問者が最初に着地するページを分析し、ユーザーの関心領域を把握。その関心に合わせたリード獲得コンテンツ（ホワイトペーパー等）を企画する。

### 🔧 GA4操作手順

1. **GA4管理画面にログイン**
2. 左側メニューから「**レポート**」をクリック
3. 「**ライフサイクル**」→「**エンゲージメント**」を選択
4. 「**ランディングページ**」レポートを開く

### 📊 確認するポイント

- ✅ セッション数が多いページ
- ✅ 特定カテゴリへの流入傾向
- ✅ エンゲージメント率の高いページ
- ✅ 直帰率の低いページ

### 📈 実データ例（Google Merchandise Store）

| ページ | 表示回数 | 前期比 | 推定CVR | 特徴 |
|--------|----------|--------|---------|------|
| Home | 14,000 | +11.1% | 1.0% | 最多流入 |
| New（新商品） | 4,348 | **+25.7%** | 1.8% | **急成長** |
| Bags | 2,498 | **+32.1%** | 2.0% | **高CVR** |
| Sale | 2,063 | +18.7% | **2.5%** | **最高CVR** |
| Men's / Unisex | 3,367 | +13.2% | 1.5% | アパレル |

### 🔍 発見事項

1. **「New（新商品）」への強い関心**（+25.7%成長）
   - 訪問者は最新トレンド・限定商品に敏感
   
2. **「Bags」カテゴリの爆発的成長**（+32.1%）
   - 実用性が高く、ギフト需要もある
   
3. **「Sale」ページの高CVR**（2.5%）
   - 価格感度の高いセグメントが存在

### 🤖 AI活用：コンテンツ企画プロンプト

詳細は [`prompts/workflow1-content-planning.md`](./prompts/workflow1-content-planning.md) を参照

これは、訪問者が「アパレル業界の動向や販売戦略」に強い関心を持っているという仮説が立てられます。

# 依頼

## ワークフロー2: ファネル分析とUI/UX改善

### 📍 目的
ユーザーの行動フロー（訪問→カート追加→購入）を分析し、離脱が多い箇所（ボトルネック）を特定。UI/UXの改善施策を立案する。

### 🔧 GA4操作手順

1. GA4管理画面で「**探索**」をクリック
2. 「**ファネルデータ探索**」を選択
3. 以下のステップでファネルを作成：
   - **ステップ1**: `session_start`（訪問開始）
   - **ステップ2**: `add_to_cart`（カート追加）
   - **ステップ3**: `purchase`（購入完了）

### 📊 実データ分析結果

```
ステップ1: session_start（訪問開始）
   📍 16,000セッション
        ↓
        | 離脱率: 82.1%  ← 第1ボトルネック
        ↓
ステップ2: add_to_cart（カート追加）
   📍 2,859件
        ↓
        | 離脱率: 91.5%  ← 第2ボトルネック（重大）
        ↓
ステップ3: purchase（購入完了）
   📍 243件

総合CVR: 1.35%（業界平均2-3%を下回る）
```

### 🚨 発見されたボトルネック

#### **第1ボトルネック: セッション → カート追加**
- **転換率**: 17.9%
- **離脱ユーザー**: 約13,141セッション
- **問題**: ユーザーの8割以上が商品をカートに追加せず離脱

#### **第2ボトルネック: カート追加 → 購入完了**
- **転換率**: 8.5%
- **離脱ユーザー**: 2,616件
- **問題**: カートに追加したユーザーの9割以上が購入未完了

### 🤖 AI活用：UI/UX改善プロンプト

詳細は [`prompts/workflow2-uiux-improvement.md`](./prompts/workflow2-uiux-improvement.md) を参照

**基本プロンプト:**

```markdown
# 役割
あなたは、UI/UX改善とEFO（エントリーフォーム最適化）の専門家です。

# 状況（事実）
GA4のファネル分析で、「カート追加（add_to_cart）」から「購入完了（purchase）」までの
離脱率が91.5%と判明しました。

# 依頼
この離脱率が異常に高い原因として考えられる「仮説」を5つ挙げてください。
また、その仮説を検証し、離脱率を改善するための具体的な「A/Bテスト案」を3つ提案してください。
```

### 💡 AI回答例：原因仮説（5つ）

1. **チェックアウトプロセスの複雑性**
   - ステップ数が多すぎる（5ステップ以上）
   - 入力項目が過剰

2. **予期しないコスト表示**
   - カート段階で見えなかった配送料が突然表示
   - 業界調査では離脱理由の55%を占める

3. **モバイル環境での操作性問題**
   - フォーム入力がモバイルに最適化されていない
   - オートフィル機能が不十分

4. **信頼性・セキュリティへの不安**
   - セキュリティバッジが不明瞭
   - 返品・返金ポリシーが見つけにくい

5. **決済方法の選択肢不足**
   - クレジットカードのみで、PayPal/Apple Pay等がない

### 💡 AI回答例：A/Bテスト案（3つ）

#### **テストA: チェックアウトステップの簡素化**

| 項目 | コントロール群 | テスト群 |
|------|--------------|---------|
| ステップ数 | 5ステップ | 1ページ完結 |
| 入力項目 | 7-10項目 | 3-4項目（必須のみ） |
| 予測効果 | 離脱率 91.5% | 離脱率 75%以下 |

#### **テストB: 信頼性シグナルの強化**

**追加要素:**
- 「100%安全決済保証」バッジ
- 「30日間返品無料」表示
- 「今月〇〇人が購入」社会的証明
- Norton/McAfeeセキュリティバッジ

**予測効果:** 離脱率 91.5% → 82%以下

#### **テストC: CTAボタンとマイクロコピーの最適化**

| 要素 | 改善前 | 改善後 |
|------|--------|--------|
| ボタン文言 | 「注文を確定する」 | 「今すぐ購入（在庫残りわずか）」 |
| ボタン色 | グレー/ブルー | アクションオレンジ |
| ボタンサイズ | 320px幅 | 480px幅（1.5倍） |
| 配置 | ページ下部のみ | スティッキー（追従） |

**予測効果:** 離脱率 91.5% → 85%以下

詳細な実装ガイドは [`guides/ab-testing-guide.md`](./guides/ab-testing-guide.md) を参照

## ワークフロー3: トラフィック獲得分析と集客戦略

### 📍 目的
流入経路（チャネル）別のパフォーマンスを分析し、各チャネルの特性に応じた最適な集客戦略を立案する。

### 🔧 GA4操作手順

1. 「**レポート**」→「**集客**」→「**トラフィック獲得**」を開く
2. 流入経路別（Paid Search、Organic Search等）のセッション数とCVRを確認
3. 各チャネルの「purchase（購入完了）」率を比較分析

### 📊 実データ分析結果

| チャネル | セッション数 | 構成比 | 前期比 | CVR（推定） | 購入数（推定） |
|---------|------------|--------|--------|------------|--------------|
| **Organic Search** | 6,817 | 38% | +12.8% | 1.2% | 82件 |
| **Direct** | 6,342 | 35% | +10.3% | 1.5% | 95件 |
| **Unassigned** | 2,428 | 13% | +1.4% | 0.5% | 12件 |
| **Paid Search** | 1,114 | 6% | **+40.1%** | **3.8%** | 42件 |
| **Referral** | 795 | 4% | +16.5% | 1.0% | 8件 |
| **Cross-network** | 507 | 3% | +56.0% | 0.8% | 4件 |
| **Email** | 273 | 2% | +77.4% | 2.2% | 6件 |

### 🔍 重要な発見

#### **Paid Search（有料広告）**
- ✅ **CVR 3.8%**（総合CVRの2.9倍）= 高品質トラフィック
- ✅ **前期比 +40.1%**（最も急成長）
- ⚠️ セッション数は全体の6%のみ = **機会損失の可能性**

#### **Organic Search（自然検索）**
- ✅ **最大チャネル**（38%のシェア）
- ✅ 安定成長（+12.8%）
- ⚠️ CVR 1.2% = **改善余地が大きい**

### 🤖 AI活用：集客戦略立案プロンプト

詳細は [`prompts/workflow3-traffic-strategy.md`](./prompts/workflow3-traffic-strategy.md) を参照

**基本プロンプト:**

```markdown
# 役割
あなたは、Web広告とSEOの両方に精通したデジタルマーケティング戦略家です。

# 状況（事実）
GA4の集客レポートで以下の事実が判明しました。
- Paid Search: セッション数 1,114, CVR 3.8%, 前期比 +40.1%
- Organic Search: セッション数 6,817, CVR 1.2%, 前期比 +12.8%

※CVRが高いほど優良なリードと仮定します。

# 依頼
この状況に基づき、「Paid Search」と「Organic Search」それぞれに対して
取るべき「仮説」と「ネクストアクション（施策）」を提案してください。
```

### 💡 AI回答例：Paid Search戦略

#### **仮説**
1. 顕在層にリーチできているが、予算制約で機会損失が発生
2. 費用対効果の高いキーワードに予算が集中しすぎている
3. デバイス別でパフォーマンス差がある

#### **ネクストアクション**

| 優先度 | アクション | 期待効果 |
|--------|-----------|---------|
| ★★★ | 予算20%増額テスト | セッション +21%, 購入 +9件/週 |
| ★★★ | 高CVRキーワード拡張 | 新規KW 15-20個追加 |
| ★★★ | デバイス別入札調整 | CPA 10-15%改善 |
| ★★ | ショッピング広告シフト | CVR 3.8% → 5-6% |
| ★★ | リマーケティング拡充 | カート放棄ユーザー15-20%再獲得 |

### 💡 AI回答例：Organic Search戦略

#### **仮説**
1. 情報収集層（潜在層）の流入が多く、購買準備度が低い
2. 流入ページとオファーがミスマッチ
3. 購買意欲の高いキーワードでの順位が低い

#### **ネクストアクション**

| 優先度 | アクション | 期待効果 |
|--------|-----------|---------|
| ★★★ | 流入上位ページのCTA最適化 | カート追加率 +50% |
| ★★★ | 内部リンク構造改善 | ページ/セッション 2.3 → 3.5 |
| ★★ | 購買KWでのコンテンツ強化 | 追加流入 +800-1,000/週 |
| ★★ | モバイルUX徹底最適化 | モバイルCVR 2倍 |
| ★★ | コンテンツマーケティング | ブランド検索 +30% |

## 使い方

### 🚀 クイックスタート

1. **このリポジトリをクローン**
   ```bash
   git clone https://github.com/yourusername/ga4-ai-workflow.git
   cd ga4-ai-workflow
   ```

2. **GA4デモアカウントにアクセス**
   - [GA4デモアカウント](https://support.google.com/analytics/answer/6367342?hl=ja)にアクセス

3. **ワークフローを順に実践**

4. **結果を記録・共有**
   - `templates/` フォルダの分析シートを活用
   - 自社の成果を記録してPDCAを回す
