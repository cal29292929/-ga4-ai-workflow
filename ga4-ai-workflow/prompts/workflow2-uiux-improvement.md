# ワークフロー2: ファネル分析 → AIによるUI/UX改善提案

## 概要

GA4のファネル分析で発見した「ボトルネック（離脱が多い箇所）」を基に、生成AIを活用してUI/UX改善の仮説とA/Bテスト案を立案します。

---

## 🎯 このワークフローで達成できること

- ✅ 定量データに基づいた離脱原因の仮説立案
- ✅ EFO（エントリーフォーム最適化）の具体的施策
- ✅ 実行可能なA/Bテスト案の自動生成
- ✅ 費用対効果の予測シミュレーション

---

## 📊 前提：GA4で確認すべきデータ

### GA4操作手順

1. GA4管理画面 > **探索** > **ファネルデータ探索**
2. 以下のステップでファネルを作成：
   - **ステップ1**: `session_start`（訪問開始）
   - **ステップ2**: `add_to_cart` または カート追加相当のイベント
   - **ステップ3**: `purchase` または コンバージョン完了イベント

### 分析のポイント

| ステップ | 確認内容 |
|---------|---------|
| **各ステップの通過率** | どこで最も多くのユーザーが離脱しているか |
| **デバイス別の差異** | モバイル vs デスクトップの離脱率差 |
| **流入元別の差異** | Organic vs Paid の離脱率差 |
| **時系列の変化** | 離脱率が悪化している箇所はないか |

## 📝 実例：Google Merchandise Store（カート放棄問題）

### 入力するデータ

```markdown
# 役割
あなたは、UI/UX改善とEFO（エントリーフォーム最適化）の専門家です。
Webサイトのコンバージョン率改善に10年以上の実績があります。

# 状況（事実）
GA4のファネル分析で、以下の事実が判明しました:

【ファネルデータ】
- ステップ1（session_start / 訪問開始）: 16,000セッション
- ステップ2（add_to_cart / カート追加）: 2,859件（離脱率 82.1%）
- ステップ3（purchase / 購入完了）: 243件（離脱率 91.5%）

【総合CVR】1.35%（業界平均2-3%を大きく下回る）

特に、**ステップ2（カート追加）からステップ3（購入完了）への離脱率が91.5%**と異常に高いことが判明しました。
これは、カートに商品を追加したユーザーの9割以上が購入を完了していないことを意味します。

【追加情報】
- 客単価: 約5,000円
- 主要デバイス: モバイル60%, デスクトップ40%（推定）
- 商品カテゴリ: アパレル、バッグ、アクセサリー

# 依頼
この離脱率91.5%が異常に高い原因として考えられる「仮説」を5つ挙げてください。
また、その仮説を検証し、離脱率を改善するための具体的な「A/Bテスト案」を3つ提案してください。

# 制約条件
- 仮説は定量データまたは業界ベンチマーク（例: Baymard Instituteの調査）で裏付けること
- A/Bテスト案は実装難易度（低/中/高）と期待効果（離脱率改善%）を明記すること
- 費用対効果のシミュレーション（増加購入数・売上）を含めること
- 実装期間の目安を示すこと
```

### 期待されるAI回答例

#### 原因仮説（5つ）

**仮説1: チェックアウトプロセスの複雑性**
- **根拠**: 
  - ステップ数が多すぎる（業界標準は3-4ステップ）
  - Baymard調査: 平均的なECサイトは5.08の入力フィールドがカート放棄の原因
- **検証方法**: 
  - ヒートマップ分析でフォーム途中の離脱箇所を特定
  - セッションリプレイで実際のユーザー行動を観察

**仮説2: 予期しないコスト（配送料・手数料）の表示**
- **根拠**: 
  - Baymard調査: カート放棄理由の55%が「予期しない追加費用」
  - カート段階では見えなかった配送料がチェックアウトで突然表示
- **検証方法**: 
  - チェックアウトページでの滞在時間分析（短い場合は価格ショックの可能性）
  - 配送料表示タイミングと離脱率の相関調査

**仮説3: モバイル環境での操作性の問題**
- **根拠**: 
  - トラフィックの60%がモバイル
  - モバイルCVRはデスクトップの1/2-1/3が業界平均
- **検証方法**: 
  - デバイス別の離脱率比較（GA4のデバイスカテゴリ分析）
  - モバイルユーザビリティテスト実施

**仮説4: 信頼性・セキュリティへの不安**
- **根拠**: 
  - セキュリティバッジ（SSL証明書、決済保証）が不明瞭
  - 初回訪問ユーザーは信頼構築前に決済情報入力を求められる
- **検証方法**: 
  - ユーザーアンケート（離脱ユーザーへのポップアップ調査）
  - 新規 vs リピーターの離脱率比較

**仮説5: 決済方法の選択肢不足**
- **根拠**: 
  - クレジットカードのみの場合、希望する決済方法がないユーザーが離脱
  - PayPal/Apple Pay/Google Pay等の導入で平均CVR 15-20%向上（Stripe調査）
- **検証方法**: 
  - 決済方法選択ページでの離脱率分析
  - 競合サイトの決済方法ベンチマーク調査

#### A/Bテスト案（3つ）

### **テストA: チェックアウトステップの簡素化**

**実装内容:**

| 項目 | コントロール群（現状） | テスト群（改善案） |
|------|---------------------|-------------------|
| ステップ数 | 5ステップ | **1ページ完結** |
| 入力項目 | 7-10項目 | **3-4項目**（必須のみ） |
| プログレス表示 | なし | **進捗バー追加** |
| オートフィル | 部分的 | **完全対応** |

**具体的な改善:**
```
【現状】
Step 1: カート確認
Step 2: 配送先入力（7項目）
Step 3: 配送方法選択
Step 4: 決済情報入力
Step 5: 注文確認

↓

【改善案】
ワンページチェックアウト:
- 配送・決済情報を1画面に統合
- 必須項目のみ表示（名前・メール・住所・決済方法）
- リアルタイムエラーチェック
- 「あと〇〇円で送料無料」プログレスバー
```

**実装難易度:** 中〜高
**実装期間:** 3-4週間
**予測効果:**
- 離脱率: 91.5% → **75%以下**（改善率: 18%+）
- 週間購入数: 243件 → 約**400件**（+157件）
- 月商増加: 約**314万円**（客単価5,000円 × 157件 × 4週）

**ROI計算:**
- 開発コスト: 約50-80万円
- 月商増加: 314万円/月
- **投資回収期間: 約1ヶ月**

## 💡 プロンプト改善のヒント

### より良い回答を得るためのコツ

1. **競合ベンチマークを含める**
   ```markdown
   # 追加情報
   競合サイトの調査:
   - 競合A社: カート放棄率 70%（業界標準）
   - 競合B社: ワンページチェックアウト採用、カート放棄率 62%
   ```

2. **ユーザーフィードバックを追加**
   ```markdown
   # ユーザーの声（定性データ）
   - 「入力項目が多すぎて面倒だった」（30%）
   - 「送料が高くて驚いた」（25%）
   - 「モバイルで入力しづらかった」（20%）
   ```

3. **制約条件を明確にする**
   ```markdown
   # 制約条件
   - 開発予算: 最大100万円
   - 実装期間: 2ヶ月以内
   - 既存システム: Shopify（プラグインで対応可能）
   ```
